# Customer Churn Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing customer churn using **Power BI** and **SQL Server**.

The objective is to identify customer churn patterns, understand the factors associated with customer attrition, and provide interactive business insights through a Power BI dashboard.

---

## 🎯 Project Objective

Customer churn can significantly affect business revenue and customer retention.

This project analyzes customer data to answer questions such as:

- How many customers have churned?
- What is the overall churn rate?
- Which customer segments have higher churn?
- Which factors are associated with customer churn?
- How does churn vary across different customer categories?

---

## 🛠️ Technologies Used

- **Power BI** – Data visualization and dashboard development
- **SQL Server** – Data storage and SQL-based data analysis
- **SQL** – Data querying and transformation
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculated metrics
